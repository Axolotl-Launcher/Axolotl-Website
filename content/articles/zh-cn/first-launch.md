第一次打开 Axolotl，最重要的是让启动器知道三件事：用哪个账户、用哪套 Java、给游戏多少内存。其余设置都可以之后再调。

## 1. 登录账户

在账户页选择 Microsoft 登录，按浏览器提示完成授权。启动器只保存登录会话，不会保存你的密码。如果你使用离线账户或自建认证服务，可以在同一页面切换到对应方式。

登录后建议先确认账户状态：头像、用户名和皮肤是否正常。如果皮肤没有刷新，重新进入账户页即可。

## 2. 选择 Java

Java 版本需要与 Minecraft 版本匹配。启动器会优先使用你选择的运行时；没有合适版本时，会提示你安装或选择其他路径。

- 新版游戏通常需要 Java 21 或更高版本。
- 旧版整合包可能锁定 Java 8 或 Java 17。
- 不要同时把多个 Java 路径指向同一个目录。

如果你不确定，保留默认的“自动选择”，让启动器按版本决定。

## 3. 分配内存

内存不是越大越好。给游戏分配过多内存，反而会让垃圾回收停顿更明显，也会挤占系统和其他程序。

| 场景           | 建议内存 |
| -------------- | -------- |
| 原版或轻量整合 | 2–4 GB   |
| 中型整合包     | 4–6 GB   |
| 大型整合包     | 6–8 GB   |

同时给操作系统留出至少 4 GB。8 GB 内存的电脑不建议把游戏分配到 6 GB 以上。

## 4. 选择游戏目录

默认目录位于用户目录下。把游戏目录放在空间充足、非网络同步盘的本地磁盘上，可以减少文件锁和读写冲突。

完成这四步后，回到主页选择版本并启动。第一次启动会下载资源，耗时取决于网络和磁盘速度。
