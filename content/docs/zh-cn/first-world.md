# 怎么开始玩MC \| 创建新世界

# 02 · 快速上手

## 认识主页

启动器打开后默认在主页。极简主页只有一句问候语和一个最近实例，点「开始游戏」直接玩：

右下角的切换按钮可以把主页换成**小组件布局**——日历、固定世界、最近项目、固定服务器一目了然：

小组件的位置和大小都可以自由调整，想显示什么在 **设置 → 首页与导航** 里配置。

## 创建第一个实例

「实例」就是一套独立的 Minecraft：游戏版本 \+ 加载器 \+ 模组的组合。

1. 点侧边栏的 **＋（创建实例）**，选择「全新创建」：

    

2. 填写名称、选游戏版本、选加载器，点「创建实例」：

    

- **游戏版本**：正式版 / 快照版 / 愚人节版 / 远古版都可以选，不确定就选最新正式版

- **加载器**：`None` 是原版；装模组一般选 Fabric（轻量、更新快）或 NeoForge / Forge（大型整合包常用）；Quilt、OptiFine、Cleanroom 等也都在列表里

    

3. 创建完成后，实例会出现在侧边栏和实例库里。

    

嫌麻烦？直接去 **发现内容** 挑一个喜欢的整合包一键安装，模组什么都不用管，见 \[04-内容中心\]\(04-内容中心.md\)。

## 启动游戏

在主页或实例库点「开始游戏」。第一次启动会自动下载 Minecraft 本体、Java 运行时和依赖，全部自动完成，等进度条走完游戏就会弹出。

游戏启动后启动器默认进入轻量模式（只留一个小窗），可以在 **设置 → 外观** 里改成最小化或保持不变。
