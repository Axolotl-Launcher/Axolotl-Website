## 先搞懂：为什么需要账户？

Minecraft Java 版有两种登录方式，你只需要选一种：

### 方式一：微软账户（正版，花钱）

**微软账户** = 你买的正版 Minecraft 账号（[Minecraft: Java \&amp; Bedrock Edition for PC](https://www.microsoft.com/zh-cn/p/minecraft-java-bedrock-edition-for-pc/9nxp44l49shj)，在微软商店购买，目前国区 **89 元**，价格可能随官方活动变动，以微软商店实时显示为准）。

买正版的好处：

- 可以进**所有服务器**（包括开启正版验证的服务器）

- 在线模式玩，别人能看到你的正版皮肤、披风

- 微软官方账户，稳定可靠

怎么登录：

1. 在主界面找到账户区域（一般在左上角或首页），点击\&\#34;添加账户\&\#34; / \&\#34;登录\&\#34;

2. 选择\&\#34;微软账户\&\#34;

3. 会弹出一个网页让你登录微软账号并授权

4. 授权完成，自动回到启动器，登录成功

### 方式二：离线账户（免费）

**离线账户** = 不花钱，随便起个名字就能玩。

适合：

- 还没决定要不要买正版，先体验一下

- 只玩单人模式，或者进不验证正版的服务器

怎么创建：

1. 点击\&\#34;添加账户\&\#34; → 选择\&\#34;离线账户\&\#34;

2. 输入你想要的游戏名（随便起，比如你喜欢的昵称）

3. 完成，就这么简单

> 注意：离线账户进不了开启\&\#34;正版验证\&\#34;的服务器（很多大型服务器都开着），也显示不了正版皮肤。可以先离线体验，喜欢再补票正版。

## 常见问题

**Q：我没有微软账号怎么办？**
A：去 [account.microsoft.com](https://account.microsoft.com) 免费注册一个（不需要买游戏也能注册），再登录启动器。

**Q：正版和离线能同时有吗？**
A：可以！启动器支持多个账户，随时切换。比如你有正版账户，也可以加个离线账户玩小号。

**Q：登录时提示\&\#34;认证服务器不可达\&\#34;？**
A：是网络问题（认证服务器有时会被干扰）。可以稍等重试，或者换网络环境（比如手机热点）试试。
