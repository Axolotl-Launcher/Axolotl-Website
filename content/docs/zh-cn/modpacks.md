# 怎么安装模组和整合包 \| 内容中心

# 04 · 内容中心

## 搜索内容

侧边栏点 **发现内容**。顶部标签切换内容类型：**整合包 / 模组 / 资源包 / 数据包 / 地图 / 光影包 / 投影 / 服务器 / 收藏夹**。

内容同时聚合了 **Modrinth** 和 **CurseForge** 两大平台，来源按钮可以切换「所有来源 / 仅 Modrinth / 仅 CurseForge」。

右侧筛选面板：

- **类别**：多人 / 科技 / 冒险 / 魔法 / 轻量……按玩法筛选

- **包含内容**：筛“必须包含某个模组”的整合包（比如一定要有 Create）

- **运行环境**：客户端 / 服务端

- **游戏版本**：只看你这个版本能用的内容

- **加载器**：Fabric / Forge / NeoForge……

- 顶部还有个「翻译」按钮，把项目介绍一键翻译成中文

    

## 安装到实例

1. 点进任意项目，看介绍、图库、版本、更新日志：

    

2. 点右上角 **安装** 按钮

3. 选择要装到哪个实例（或新建实例），确认依赖后开始安装

4. 安装进度在 **下载** 页面实时可见

    

安装整合包 = 全自动：模组、依赖、配置一次性到位。安装单个模组时启动器会提示缺失的前置（Fabric API 之类），默认自动补齐。

## 版本选择

项目详情页点 **版本** 标签，可以指定任意历史版本安装——整合包回滚、模组降级都靠这里。下载时也能在安装弹窗里直接指定版本。

## 收藏夹

看到喜欢的项目先收藏，点顶部 **收藏夹** 标签随时回来看：

## 下载管理

顶栏的 **⬇ 图标**（或侧边栏下载页）打开下载中心：

- **正在进行**：当前任务进度、失败重试

- **历史记录**：已完成 / 失败的任务都在

- 右上角 **新建下载** 可以手动添加任务

- 下载速度不理想？点提示里的「下载设置」开启**强制多连接下载（后期会默认开启此选项）**

    

## 模组更新

- 单个更新：实例 → 内容 → 模组行的 ⬇ 图标

- 批量更新：勾选所有可更新项 → 右下角批量下载

- **整合包实例里的模组**默认跟随整合包整体更新，不能单独更新；想单独管理就先「解除整合包关联」
