# 08 · 设置详解

设置页左侧分三组：**界面 / 游戏 / 数据与隐私**，顶部有搜索框，找设置直接搜：

外观、首页与导航、皮肤相关的内容见 \[06-皮肤与个性化\]\(06-皮肤与个性化.md\)，这里讲剩下的。

## 界面

### 语言与翻译

- **界面语言**：三十多种语言随便换，简体中文最全

- **翻译服务**：项目介绍一键翻译用的引擎

    - Microsoft 翻译已不可用，推荐 **Google 翻译优选**（国内可用，注意\&\#34;可用\&\#34;旁的数字，0 = 当前用不了）

    - 配置了 AI 的话可以选 **AI 模型** 翻译，质量更好

        

### AI 功能

配置自己的 AI 供应商（API 地址 \+ 密钥），开启后可用：

- AI 翻译（翻译服务选 AI 模型）

- AI 崩溃解释（游戏崩溃后让 AI 分析日志说人话）

    

启动器不提供免费 API，请使用自己的AI API。

### 键盘快捷键

自定义全局和界面内快捷键，比如启动器的呼出键。

### MCP 服务器

给 AI 客户端接入启动器能力的接口，玩 AI 自动化的进阶功能。

## 游戏

### 启动默认值

所有实例默认继承的配置：Java 版本、内存分配、启动前操作等。单独给某个实例改的值会覆盖这里（见《怎么管理实例\|关于实例的所有》）。

### Java 与性能

启动器按版本自动管理 Java：Java 25 / 21 / 17 / 8 各有一个位置，点 **安装推荐版本** 自动下载对应的运行时，也可以 **检测** 本机已有的 Java 或 **浏览** 手动指定路径。

正常情况下你不需要碰它——启动器会自动给实例选对版本。

内存分配在 **默认实例选项** 里调（自动 or 手动指定最大内存），还可以开「启动前内存优化」。

### 内容与下载

- **下载来源**：Modrinth / CurseForge 的镜像与站点选择

- **强制多连接下载**：下载慢就开这个（下载页的提示也会带你过来）

- 高级下载信息、安装行为（自动安装前置、安装未知整合包前提醒）

    

### 网络与多人游戏

- **代理**：启动器下载和联机的代理设置

- **陶瓦公共节点**：自定义陶瓦联机的节点列表，每行一个 URI（`wss://` 等），留空用内置节点

- 联机相关诊断

    

### 实例同步

多台电脑之间同步实例（配置、存档跟随），需要登录账号后使用。

## 数据与隐私

### 存储与备份

- **存储位置**：实例、元数据、缓存放哪，支持迁移

- **备份库**：备份文件的管理和清理

    

### 第三方账户

添加 authlib-injector 外置登录服务（LittleSkin 等）：填服务器的 Yggdrasil API 地址即可登录对应账号。

### 隐私与数据共享

遥测与数据收集开关，介意的话在这里关。

### 日志与诊断

启动器自身日志的级别、打开日志目录、诊断工具。给开发者报 bug 时用。

## 更新

检查更新、切换更新频道（正式 / Beta / Alpha）、查看更新日志，详见 \[01-安装与更新\]\(01-安装与更新.md\)。

版本号、开源地址、赞助入口、许可证（GPL 3.0）。启动器完全开源，欢迎审查和贡献。
